# 顧客登録フォーム（見本）

架空の会社がお客さんに送る「顧客登録フォーム」の見本です（1ページ・HTML / CSS / JavaScript）。
お客さんに「この画面で請求先と配送先を登録してもらいます」と説明するための画面です。

- 公開ページ: https://shingo-portfolio.github.io/register-form/
- 英語と日本語を切り替えられます（入力した値は残ります）
- 請求先・配送先（必要なときだけ表示）・担当者を入れる3つの囲みがあります
- 国と国番号は、国名・国コード・国番号で絞り込んで選べます（キーボードでも操作できます）
- 入れ漏れがあると、登録の前に上の赤い帯で1つずつ知らせます
- 「見本の値を入れる」で架空の値が入り、そのまま登録完了の画面まで体験できます
- 入力は保存も送信もしません。サーバー・データベース・外部の通信も使いません
- 言葉と国の一覧は `js/data.js`、色・文字・余白などの値は `css/tokens.css` にまとめ、`css/components.css` はその値だけを使っています
- パソコンとスマホの幅に対応しています
- 仕上がりの画面: `screenshots/`（英語 1440px・日本語 375px・入れ漏れの知らせ 375px・登録完了 1440px）
